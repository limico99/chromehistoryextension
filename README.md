# 방문기록 날짜별 선택 삭제 (크롬 확장 프로그램)

크롬 방문기록을 날짜별로 확인하고, 원하는 항목만 골라서 삭제하는 확장 프로그램입니다.
공식 `chrome.history` API만 사용하며, 서버나 파일 접근 없이 브라우저 안에서 완전히 동작합니다.

## 설치 방법 (개발자 모드로 압축해제된 확장 프로그램 로드)

1. 압축을 원하는 폴더에 풉니다. (예: `C:\tools\chrome-history-extension`)
2. 크롬 주소창에 `chrome://extensions` 입력 후 이동합니다.
3. 오른쪽 위 **"개발자 모드"** 토글을 켭니다.
4. **"압축해제된 확장 프로그램을 로드합니다"** 버튼 클릭 → 압축을 푼 폴더(`manifest.json`이 있는 폴더)를 선택합니다.
5. 툴바에 아이콘이 추가됩니다. 아이콘 클릭 → **"관리 화면 열기"**.

## 사용 방법

1. 확장 아이콘 클릭 → 팝업에서 **"관리 화면 열기"** 클릭 (새 탭에서 전체 화면이 열립니다).
2. 상단 **"조회 범위"**에서 얼마나 오래된 기록까지 불러올지 선택합니다 (7일~1년). 범위가 넓을수록 불러오는 데 시간이 더 걸릴 수 있습니다.
3. 왼쪽에서 삭제하고 싶은 **날짜**를 클릭하면 오른쪽에 그날의 방문기록이 시간순으로 나타납니다. 체크박스로 원하는 항목만 선택 후 **"선택 항목 삭제"**.
4. 왼쪽 날짜 목록의 **체크박스**로 여러 날짜를 골라 **"선택 날짜 삭제"**로 한 번에 삭제할 수 있습니다.
5. 상단 검색창에 URL/제목 키워드를 입력하면 **전체 기록을 대상으로 검색**해서 보여줍니다 (조회 범위와 무관, 최대 500건). 결과에서도 체크박스로 선택 삭제 가능합니다.
6. 왼쪽 하단 **"날짜 범위 일괄 삭제"**에서 시작일~종료일을 지정하면 개별 선택 없이 해당 기간 전체를 한 번에 삭제합니다.
7. 상단 **"삭제 전 백업 파일(JSON) 다운로드"** 체크박스가 켜져 있으면, 삭제 직전 삭제될 항목 목록이 JSON 파일로 자동 다운로드됩니다. 이 설정은 브라우저를 껐다 켜도 유지됩니다.

## 기존 데스크톱(Python) 버전과 달라진 점

확장 프로그램은 크롬 내부 공식 API로 동작하기 때문에 이전 방식과 몇 가지 차이가 있습니다.

- **브라우저를 끌 필요 없음**: `chrome.history` API는 크롬이 켜져 있는 상태에서 안전하게 삭제를 처리합니다. 파일 잠금 문제가 없습니다.
- **프로필 선택 불필요**: 확장 프로그램은 설치된 프로필의 기록만 다룹니다. 다른 프로필의 기록도 관리하려면 그 프로필에도 이 확장을 설치하면 됩니다.
- **백업 방식 변경**: 확장 프로그램은 브라우저의 History 파일에 직접 접근할 수 없어서, "자동 백업"은 원본 파일 복사가 아니라 **삭제될 항목 목록을 JSON으로 다운로드**하는 방식입니다. 완전한 되돌리기(복원)는 지원하지 않고, 무엇이 삭제되었는지 확인·참고하는 용도입니다.
- **크롬 전용**: 요청에 따라 Edge / 네이버 웨일 / Firefox 지원은 제외했습니다.

## 알아두면 좋은 점

- 왼쪽 날짜 목록은 **상단에서 선택한 조회 범위** 안에서만 만들어집니다. 그 범위보다 오래된 날짜를 삭제하려면 조회 범위를 늘리거나(최대 1년), 검색 기능을 사용하세요 (검색은 전체 기록 대상).
- 즐겨찾기(북마크)는 건드리지 않고 방문기록만 삭제합니다.
- 방문한 고유 URL 수가 매우 많은 경우, 최초 로딩(및 새로고침) 시간이 다소 걸릴 수 있습니다.
- 백업 JSON에는 삭제 시점 기준으로 조회 범위 안에 있던 항목만 기록됩니다 (날짜 범위 삭제 시 조회 범위 밖의 날짜까지 지정하면, 실제 삭제는 정상적으로 되지만 백업 로그에는 빠질 수 있습니다).
